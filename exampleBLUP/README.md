# Full example estimation of inbreeding depression load and its variance components 

S Antonios et al., 2024, supplementary material to manuscript "Genetic inbreeding load and its prediction in French dairy sheep".

This example uses the pedigree of five individuals in Varona et. al. (2019, Genet Sel Evol (2019) 51:78, Fig. 1) <https://doi.org/10.1186/s12711-019-0521-3>. It is in the file `ped.LV` and it is renumbered parents before offspring, and missing parents are indicated as 0. The fourth column in the example is ignored.

## Get partial inbreeding coefficients

First we run `getPartialInbreeding.f90` from <https://github.com/alegarra/getPartialInbreeding> e.g. :

```
$ gfortran -g -Wall -fbounds-check -fbacktrace -ffpe-trap=invalid,zero,overflow   getPartialInbreeding.f90 -o getPartialInbreeding
$ ./getPartialInbreeding ped.LV 
```


The output `PartialInbreeding.txt1to5` has 4 lines. The partial inbreeding coefficient of 0.250 is obtained for the animal 4 generated by individual 1, and three partial inbreeding coefficients (0.1875, 0.0625, and 0.125) for animal 5, generated by individuals 1, 2, and 3, respectively. 

```
$ cat PartialInbreeding.txt1to5
 
 ancestor individual Fpartial numberOfAncestors
        1        4  0.25000000                  3
        3        5  0.12500000                  4
        1        5  0.18750000                  4
        2        5  0.06250000                  4
```


## Transform partial inbreeding coefficients 

This program `TtimesImP.jl` from <https://github.com/alegarra/getPartialInbreeding> computes matrix K=T(I-P). The coefficients in K are the ones used to estimated EBVs for inbreeding depression load.   It is called as e.g.

```
$ julia TtimesImP.jl ped.LV PartialInbreeding.txt1to5 0.01
```

where the last number is a filter so that values in K with absolute value smaller than, in this example, 0.01 are not written. This is to avoid many small values that are actually not much useful for estimation (Martinez Castillero et al. J Dairy Sci 104:10040-10048). If one wants to see all values, then use a value of 0. This is the output:


```
$ cat K.txt 

        4        1        1        0.2500000000        1
        5        2        2        0.1250000000        1        0.1250000000        3
```

the first column is the animal, the second column indicates how many columns of K get a non-zero value, the third column indicates how many animals have values higher than the thresholds, and then there are pairs of (value, individual) which are the corresponding values in K. E.g. the element (5,3) of K is 0.125.

This matrix has to be included in the data file for `blupf90+` as a series of covariates, in a manner similar to a random regression model or competition model, e.g. <https://masuday.github.io/blupf90_tutorial/mrode_c08ex081_social_interaction.html>.

Individuals 3, 4, and 5 have phenotypes 113, 87, and 96, respectively. The data file is `dat.LV`:

```
$ cat dat.LV 
        113        1        3        0            0        0            0 
         87        1        4        0.250        1        0            0 
         96        1        5        0.125        1        0.125        3
```


The first column is the phenotype, the second column is the fixed effect (mean), the third column is the animal_id, and then there are pairs of (value, individual) which are the corresponding values in K. We need as many columns as needed for the maximum number of ancestors in a line of matrix K. For instance, for animal 3, the pairs of (value, individual) must be completed with zero.

Pedigree file is `ped.LV` (same as before, but not necessarily). Program `blupf90+` needs an extra information, the variance of Mendelian Sampling for each individual, and this is indicated in the 4th column of `ped.LV` in the form of an integer code. The pedigree file has the following format:

`animal number, sire number, dam number, inb/upg code`

according to explanations in <https://nce.ads.uga.edu/wiki/lib/exe/fetch.php?media=blupf90_all.pdf>, under `Parameter file for application programs`:


_...where  inb/upg code = 4000 / [(1+ms)(1-Fs) + (1+md)(1-Fd)] 
where ms (md) is 0 whenever sire (dam) is known, and 1 otherwise, and Fs(Fd) is the coefficient of inbreeding of the sire (dam)_ (which is 0 for missing sire (dam)). _For example, the inb/upg code for the animal with both parents known is 2000. The code should be an integer value...._ 

```
$ cat ped.LV

1 0 0 1000
2 0 0 1000
3 1 2 2000
4 1 3 2000
5 4 3 2286
```

Users should not use `renumf90` for this - it will change the pedigree id's, and they need to be the same as the numbers in `K.txt` which have been pasted into `dat.LV`.

## BLUP and variance component estimation

The BLUPF90 parameter file is `par.LV`:


```
$ cat par.LV
DATAFILE
 dat.LV
NUMBER_OF_TRAITS
           1
NUMBER_OF_EFFECTS
           4
OBSERVATION(S)
    1
WEIGHT(S)
 
EFFECTS: POSITIONS_IN_DATAFILE NUMBER_OF_LEVELS TYPE_OF_EFFECT[EFFECT NESTED]
# overall mean
 2      1 cross 
# animal is in col 3 and has 5 levels 
 3      5 cross
# "random regression" effects (K fraction of the ancestors in cols 5 qnd following)
# need as many columns (and effects here) as max ancestors including in the 
# inbreeding decomposition; in this case, 2 
# cov1 nested in ancestor1 (in column 5)
 4      0 cov 5  
# only the last of these lines contains the actual number of levels, previous ones contain 0
# to "cheat" blupf90 to make contributions to the MME in the same positions
# see https://masuday.github.io/blupf90_tutorial/mrode_c08ex081_social_interaction.html
 6      5 cov 7 
RANDOM_RESIDUAL VALUES
   1    
# the Varona et al paper has a mistake, this is the correct Vare
 RANDOM_GROUP
   2 3
 RANDOM_TYPE
 add_an_upginb
 FILE
ped.LV                                                                    
(CO)VARIANCES
    2  -0.25 
 -0.25   1
```
